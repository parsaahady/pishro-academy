# راه‌اندازی سایت آکادمی پیشرو در VS Code

## ۱) باز کردن پروژه
1. فایل `pishro-academy.zip` را دانلود و Extract کنید.
2. در VS Code از مسیر `File > Open Folder` پوشه پروژه را باز کنید.

## ۲) اجرای محلی
این پروژه HTML/CSS/JavaScript است و نیاز به نصب npm ندارد.

### روش پیشنهادی: Live Server
1. در VS Code افزونه **Live Server** را نصب کنید.
2. روی `index.html` راست‌کلیک کنید.
3. گزینه **Open with Live Server** را بزنید.

### روش جایگزین با Python
در Terminal وی‌اس‌کد، داخل پوشه پروژه اجرا کنید:

```bash
python -m http.server 5500
```

سپس در مرورگر باز کنید:

```text
http://localhost:5500
```

حتماً با سرور اجرا کنید و فایل‌ها را با `file://` باز نکنید؛ چون ورود ادمین، ذخیره بازیکنان و آپلود عکس به اجرای سایت روی یک آدرس مشترک نیاز دارد.

## ۳) ورود به پنل مدیریت
آدرس:

```text
http://localhost:5500/admin.html
```

اطلاعات ورود اولیه:

- نام کاربری: `admin`
- رمز عبور: `PishroAdmin!1405`

برای تغییر اطلاعات ورود، فایل `admin-config.js` را ویرایش کنید.

## ۴) اضافه کردن بازیکن
1. وارد `admin.html` شوید.
2. تیم موردنظر را انتخاب کنید.
3. روی «افزودن بازیکن» بزنید.
4. مشخصات و عکس را وارد کنید.
5. ذخیره کنید.
6. بازیکن در صفحه تیم و بخش «بازیکنان پیشرو» صفحه اصلی نمایش داده می‌شود.

اطلاعات فعلی در `localStorage` مرورگر ذخیره می‌شود. برای نسخه واقعی روی دامنه عمومی، احراز هویت و دیتابیس سمت سرور پیشنهاد می‌شود.
